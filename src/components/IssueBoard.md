# 인물별 카드 구성

`/issues`와 `/issues/:groupId`는 같은 비교표와 카드 영역을 제공한다. 숫자를 누르면 `category`로 해당 유형만 모아 보고, 카드 상세를 닫아도 필터를 유지한다. 기본 화면은 장면 설명 → 관련 카드 → 다음 장면 순서로 14장을 읽는다. 마지막에 남는 의문을 표시한다. 장수 비교표는 접어 두며 필요할 때 펼친다. `/deduction`은 이 화면으로 이동한다.

## 인물당 목표

목표는 로웬을 제외한 다섯 인물에게 적용한다. 로웬은 기존 장수만 표시하고 별도 검토로 남긴다.

- 소문 4장: 카더라 2장, 수소문 2장.
- 묻어야 하는 진실 2장.
- 측근 NPC 탐문 4장: 소문 특정 1장, 행적 추론 2장, 진실 암시 1장.
- 루시엔은 예외로 의료 가설 3장, 반증 1장.
- **전용 증거 4장**. 다른 인물의 쟁점에 함께 연결되더라도 전용 배정은 중복 집계하지 않는다.
- 욕망·파멸 단서 수는 `desire-ruin-audit.json`의 인물별 기준을 따른다. 다른 카드 분류와 겹치는 보조 역할이다.

## 집계 원본

- 소문의 인물 배정: `timeline.json/characterIdByCardId`.
- 전용 증거: `evidence-allocation.json/players`. 로웬을 포함해 여섯 인물에게 각각 4장을 배정한다.
- 공통 증거: `evidence-allocation.json/commonCardIds`의 8장. 배정 보류 증거는 없다.
- 진실의 주인: 카드의 `initialOwnerId`.
- 탐문 덱: `npc-groups.json`. 증언 대상이 다른 인물이어도 소속 NPC 덱에 집계한다.
- 탐문 유형: `card-role-audit.json/cardsByPrimaryRole`.
- 참고 증거: `issue-groups.json`의 연결 중 다른 인물에게 배정된 증거.
- 욕망·파멸: `desire-ruin-audit.json`. 차수는 실제 자동 해금이 아닌 `release-plan.json` 수동 배포안이다.
- 제출·보유·공개에 따른 점수 조건: `character-settings.json`의 카드 제목을 포함하는 승리·파멸 조건.

장수는 실제 존재하는 카드 ID를 중복 제거하여 센다. 부족·초과, 유형 누락·중복, 원본 누락을 표시한다. 장수 일치는 내용의 추론 타당성까지 뜻하지 않는다. 원고의 균형을 맞추기 위해 배정을 임의 변경하지 않는다.
