# Murder Mystery Workbench

AI가 생성한 머더 미스터리 시나리오를 검증하고 카드 기반으로 시험하는 워크벤치입니다. 《왕관재판》 게임 테이블과 설계자용 카드 라이브러리를 제공합니다. 이전 자유 테이블 기록도 보존합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 페이지 주소와 딥링크

공통 설정 `/setting`, 인물 설정 `/characters`, 카드 테이블 `/table`, 카드 라이브러리 `/library`, 쟁점 연결 `/issues`, 타임라인 `/timeline`, 추리 검증 `/deduction`을 직접 열 수 있습니다. 제목·문단의 `↗`와 `현재 화면 링크 복사`를 사용하면 인물 관계·목표, 카드 상세·필터, 쟁점의 정보 조각, 테이블의 가지·기록·선택 상태까지 지정합니다. [전체 주소와 복원 범위](docs/deep-links.md)를 참고하세요.

테이블 기록은 같은 브라우저의 저장소에 보관하여 새로고침 후 복원합니다. 링크만으로 다른 기기에 배치가 전송되지는 않습니다. 정적 배포 시에는 각 세부 경로를 `index.html`로 연결하는 서버 fallback이 필요합니다.

## 시나리오 수정

정본 데이터는 `scenarios/crown-trial/`의 분할 JSON입니다. 파일을 수정하면 개발 서버가 화면을 다시 불러오며, `schemas/`의 JSON Schema와 의미 검증기가 잘못된 타입·참조·도달 불가 카드를 보고합니다.

```text
scenarios/crown-trial/
├── scenario.json
├── characters.json
├── cards.json
├── locations.json
├── rules.json
├── memory-stages.json
├── npc-groups.json
├── timeline.json
├── deduction-audit.json
└── issue-groups.json
```

## 카드 라이브러리와 시나리오

카드 라이브러리의 `전체 / 기억 / 소문 / 물증 / 증언` 버튼으로 종류를 선택합니다. 전체 보기에서도 종류별 구역으로 나뉘며 검색은 선택한 종류 안에서 카드 본문·인물·장소·태그를 함께 찾습니다. 카드를 누르면 중앙에서 카드 자체를 확대하여 전체 본문을 읽습니다. 시작 위치·연결된 주장·원본 ID는 `설계 정보`를 눌러 같은 카드 자리에서 확인합니다.

라이브러리의 `하나씩 열기`는 카드를 뒷면으로 놓고 클릭한 카드만 펼칩니다. 펼친 카드를 다시 누르면 상세를 보고, `모두 덮기`로 다시 덮습니다.

현재 콘텐츠는 **개인 진실 18장, 소문 24장, 물증 24장, 증언 24장**으로 총 90장입니다. 각 인물은 개인 진실 3장, 전담 NPC 증언 4장, 주요 관점의 소문 4장과 물증 4장에 연결되어 총 15장씩 같은 비중을 갖습니다. 물증은 왕세자 서재·왕실 약제실·서쪽 회랑·왕실서고에 6장씩 배치됩니다.

3회 동안 여섯 사람이 매회 소문·탐문·탐색에서 한 장씩 획득하므로, 소문·증언·물증은 각각 18장씩 사용되고 6장씩 남습니다. 탐문은 매회 여섯 NPC를 한 번씩 방문해 특정 NPC로 선택이 몰리지 않게 합니다.

[공유 시나리오 대화](https://chatgpt.com/share/6aae8f28-d7f0-83ee-af3a-2954810704be)의 사건 진상과 인물 설정을 바탕으로 문구를 확장했습니다. 주요 추리 구간은 `21:52 폭행 → 22:15 생존 확인 → 22:33 이사벨 방문 → 22:38 베네딕트 입실 → 22:41 생존 목소리 → 22:49 베네딕트 귀환 → 22:55 무반응 확인`입니다. 로웬은 22시 40~48분 서쪽 외문에 있었고, 이사벨은 카시안이 22시 39~52분의 비밀 만남을 공개해야만 알리바이가 생깁니다.

라이브러리는 모든 비밀을 보는 설계자 공간입니다. 개인 진실 I은 첫 조사 전에, II는 첫 번째 재판 뒤, III는 두 번째 재판 뒤 확인합니다. 타임라인은 90장을 시간대와 주요 인물별로 배열하며, 추리 검증은 알리바이·사망 원인·현장 접근·물리적 흔적·거짓 알리바이의 대체 경로, 단일 카드 제거 내성, 서로 다른 다섯 장으로 최종 고발 칸을 채울 수 있는지를 검사합니다. 연결된 주장은 자동으로 참이 되는 정답이 아니라 재판에서 채택하거나 기각할 명제입니다.

## 1인칭 플레이테스트

게임 화면은 카드가 화면 대부분을 사용하는 전체 화면 테이블입니다. 좌상단 `왕관재판` 메뉴로 다른 작업 공간에 이동하고, 상단 중앙의 현재 단계 또는 좌하단 손패 버튼으로 진행 순서·플레이어·종류별 수집 현황을 펼칩니다. 내 인물·공개 기록·이력은 우상단, 자동 진행은 우하단의 작은 플로팅 조작부에 있습니다. 카드 선택·확대 중에는 이 조작부를 숨겨 본문을 가리지 않습니다.

`/table`에서 한 인물을 고르면 그 인물만 직접 조작하고 나머지 다섯 인물은 현재 룰에서 가능한 행동을 무작위로 선택합니다. 추론·대화 AI가 아닙니다. 내 차례에는 덱과 선택 후보가 열리고, 다른 인물의 차례에도 내 손패와 인물 설정은 유지됩니다. 다른 인물의 비공개 손패·후보·미공개 검사 결과는 표시하지 않습니다.

수집 현황은 내 기억·소문·탐문·조사 카드 수와 재판 제출 수를 보여줍니다. 매 라운드 조사 뒤에는 자동으로 멈춰 손패를 검토하고 직접 재판을 엽니다. `자동 진행 멈추기`로 다른 인물의 진행을 멈출 수 있고, 카드 확대·인물·공개 기록·이력을 읽는 동안에도 기다립니다. 새로고침이나 과거 기록으로 이동한 뒤에는 자동 진행을 명시적으로 재개합니다. 과거에서 내 선택을 바꾸면 기존 플레이는 보존하고 분기합니다.

선택한 인물과 무작위 플레이 결과도 각 스냅샷에 저장됩니다. `다른 인물로 새 테스트`는 원래 기록을 보존합니다. 예전 교대식 게임 기록에서는 인물을 선택해 같은 덱과 진행에서 이어갈 수 있습니다.

## 자유 카드 테이블

아래 자유 조작은 `/table/archive`의 기존 배치에서 사용합니다. `/table`은 차례에 맞는 덱·후보·재판 제출을 제공하는 게임 테이블입니다. 두 화면은 같은 `CardTable`을 사용하며, 게임 규칙은 `CardTablePolicy`를 통해 허용된 의도만 전달합니다. 호버·드래그·N장 선택·확대 UX의 정본 및 제품 사용처는 [카드 모듈 API와 감사 기록](src/components/CardTable.md)에 있습니다.

손패 카드는 제자리에 남고 호버 미리보기는 별도로 표시됩니다. 옆 카드로 옮기면 미리보기의 크기를 유지하고 위치·내용만 바뀝니다. 게임에서는 후보를 클릭하거나 손패로 끌어 획득하고, 재판에서는 제출 가능한 손패를 위로 끌거나 확대 화면의 제출 버튼을 사용합니다.

- 처음에는 종류별 뒷면 덱 4개를 놓습니다. 종류가 달라도 자유롭게 섞어 쌓을 수 있습니다.
- **뒷면 클릭 / 1**은 맨 위 한 장을 앞면으로 펼쳐 아래 손패로 가져오고 크게 보여줍니다. **2 / 3**은 해당 장수를 펼쳐 보고 한 장만 고릅니다. 나머지는 원래 순서대로 덱에 뒷면으로 남습니다. 취소하면 배치와 기록은 그대로입니다.
- 앞면 클릭이나 덱 이름 클릭은 선택입니다. `Shift+클릭`으로 선택을 추가·해제하고, 빈 곳을 드래그해 박스 선택합니다. `Ctrl/⌘+A`는 모두 선택입니다.
- **선택하지 않은 덱을 드래그하면 맨 위 한 장**, **선택한 덱을 드래그하면 덱 전체**를 옮깁니다. 여러 개를 선택하면 함께 이동합니다. 드래그로 꺼내는 카드는 기존 앞뒤를 유지합니다.
- 다른 묶음 가운데에 놓으면 그 위에 쌓입니다. 드래그 중에는 대상 테두리가 강조되고 `Esc`나 창 포커스 이탈로 취소합니다. 놓을 때 한 번만 기록됩니다.
- **앞면 더블클릭**은 중앙에서 크게 읽습니다. **Space 또는 Alt를 누르는 동안** 현재 면을 잠깐 확대하고, 키를 놓으면 돌아갑니다. 뒷면은 확대해도 뒷면이며 가져오기·뒤집기와 별개입니다.
- **우클릭 / Shift+F10**으로 조작 메뉴를 엽니다. 메뉴는 방향키·Enter·Esc로 조작합니다. 선택 후 상단 `동작` 버튼으로도 열 수 있습니다.
- `F`는 카드/덱 전체 뒤집기, `R`은 섞기, `G`는 선택한 묶음을 마지막 선택 위에 쌓기입니다. 상단과 우클릭 메뉴에도 `1 / 2 / 3` 펼쳐 가져오기가 있습니다. 남은 카드가 적으면 남은 장수만 보여줍니다.
- 단축키는 가리킨 카드에 우선 적용하고, 그 카드가 선택에 포함되면 선택한 묶음 모두에 적용합니다. 가리킨 카드가 없으면 키보드 초점·선택을 사용합니다. 방향키로 조금씩 이동할 수도 있습니다.
- `Ctrl/⌘+Z`로 되돌리고 `Ctrl/⌘+Shift+Z`로 다시 합니다. 검색·텍스트 입력·한글 조합 중에는 카드 단축키가 작동하지 않습니다. `?` 또는 `조작법`에서 전체 입력을 확인합니다.
- 접힌 `기록`을 펼쳐 배치를 되돌리거나 Fork합니다. 과거 배치에서 새로 조작하면 원래 기록을 보존하는 별도 가지를 만듭니다.
- 모든 앞뒷면은 **2:3**입니다. 테이블·손패·라이브러리·확대·선택 화면이 같은 카드 표현을 사용하며, 본문과 여백은 크기에 맞춰 조정합니다. 카드 내부 및 확대·선택 화면에는 스크롤이나 본문 생략이 없습니다. 라이브러리 목록 자체는 스크롤합니다.

조작은 [공식 가상 테이블 조작법 조사](docs/table-ux.md)를 바탕으로 정했습니다. 제품마다 키가 달라 모든 단축키를 하나의 보편 표준으로 주장하지 않습니다. 별도의 좌우 패널이나 카드마다 반복되는 버튼은 없습니다.

조사·소유권·공개·법정·승패는 자동 처리하지 않습니다. 진행 방식은 사용자가 결정합니다. 손패는 화면 아래의 배치 영역이며 가져온 카드도 자유롭게 옮기거나 쌓습니다. 앞뒤 상태는 로컬 화면 표시일 뿐 접근 권한이나 멀티플레이 비밀 보장이 아닙니다. 현재 배치와 기록은 같은 브라우저의 로컬 저장소에 보관되어 새로고침해도 복원됩니다. 다른 기기와 동기화되지는 않으며 저장소를 사용할 수 없으면 메모리에서만 유지됩니다. 기존 게임 규칙 엔진은 소스에 보존하되 테이블에서는 사용하지 않습니다.
