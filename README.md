# Murder Mystery Workbench

AI가 생성한 머더 미스터리 시나리오를 검증하고 카드 기반으로 시험하는 워크벤치입니다. 《왕관재판》 카드 라이브러리와 **규칙을 강제하지 않는 자유로운 2D 카드 테이블**을 제공합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 시나리오 수정

정본 데이터는 `scenarios/crown-trial/`의 분할 JSON입니다. 파일을 수정하면 개발 서버가 화면을 다시 불러오며, `schemas/`의 JSON Schema와 의미 검증기가 잘못된 타입·참조·도달 불가 카드를 보고합니다.

```text
scenarios/crown-trial/
├── scenario.json
├── characters.json
├── cards.json
├── locations.json
└── rules.json
```

## 카드 라이브러리와 시나리오

카드 라이브러리의 `전체 / 기억 / 소문 / 물증 / 증언` 버튼으로 종류를 선택합니다. 전체 보기에서도 종류별 구역으로 나뉘며 검색은 선택한 종류 안에서 카드 본문·인물·장소·태그를 함께 찾습니다. 카드를 누르면 중앙에서 카드 자체를 확대하여 전체 본문을 읽습니다. 시작 위치·연결된 주장·원본 ID는 확대 카드 아래 `설계 정보`를 펼쳐 확인합니다.

라이브러리의 `하나씩 열기`는 카드를 뒷면으로 놓고 클릭한 카드만 펼칩니다. 펼친 카드를 다시 누르면 상세를 보고, `모두 덮기`로 다시 덮습니다.

현재 콘텐츠는 **기억 12장, 소문 6장, 물증 12장, 증언 6장**입니다. 여섯 인물에게 기억 2장씩, 나머지 24장에는 서재·약제실·서쪽 회랑·왕실서고가 시나리오상 연결되어 있습니다. 이 연결은 참고 정보이며 테이블 배치를 제한하지 않습니다. 라이브러리의 `인물 설정서`를 펼쳐 읽을 수 있습니다.

[공유 시나리오 대화](https://chatgpt.com/share/6aae7427-be78-83e8-a187-57c34bf29843)의 후반 사건 진상과 인물 설정을 바탕으로 문구를 확장했습니다. 세라핀은 선왕의 딸이며, 주요 시간 단서는 `21:52 폭행 → 22:18 생존 → 22:30 술 호출 → 22:36 생존 → 22:44 재상 방문`입니다. 진상은 유지하되 카드의 구체적인 문구·문서 조각·목격 범위는 테스트용으로 각색했습니다.

라이브러리는 모든 비밀을 보는 설계자 공간입니다. 전체 게임의 라운드별 분배·해금 조건·밸런스는 아직 확정하지 않았습니다. 연결된 주장은 자동으로 참이 되는 정답이 아니라 시나리오 참고 명제입니다.

## 자유 카드 테이블

- 처음에는 종류별 뒷면 덱 4개를 놓습니다. 종류가 달라도 자유롭게 섞어 쌓을 수 있습니다.
- 클릭은 선택만 합니다. `Shift+클릭`으로 선택을 추가·해제하고, 빈 곳을 드래그해 박스 선택합니다. `Ctrl/⌘+A`는 모두 선택입니다.
- **선택하지 않은 덱을 드래그하면 맨 위 한 장**, **클릭해서 선택한 덱을 드래그하면 덱 전체**를 옮깁니다. 여러 개를 선택하면 함께 이동합니다.
- 다른 묶음 가운데에 놓으면 그 위에 쌓입니다. 드래그 중에는 대상 테두리가 강조되고 `Esc`나 창 포커스 이탈로 취소합니다. 놓을 때 한 번만 기록됩니다.
- **더블클릭**은 현재 면을 중앙에서 크게 읽습니다. **Space 또는 Alt를 누르는 동안** 잠깐 확대하고, 키를 놓으면 돌아갑니다. 뒷면은 확대해도 뒷면이며 뒤집기와 별개입니다.
- **우클릭 / Shift+F10**으로 조작 메뉴를 엽니다. 메뉴는 방향키·Enter·Esc로 조작합니다. 선택 후 상단 `동작` 버튼으로도 열 수 있습니다.
- `F`는 카드/덱 전체 뒤집기, `R`은 섞기, `1~9`는 해당 장수 꺼내기, `G`는 선택한 묶음을 마지막 선택 위에 쌓기입니다. 앞뒤는 꺼내거나 쌓아도 유지됩니다.
- 단축키는 가리킨 카드에 우선 적용하고, 그 카드가 선택에 포함되면 선택한 묶음 모두에 적용합니다. 가리킨 카드가 없으면 키보드 초점·선택을 사용합니다. 방향키로 조금씩 이동할 수도 있습니다.
- `Ctrl/⌘+Z`로 되돌리고 `Ctrl/⌘+Shift+Z`로 다시 합니다. 검색·텍스트 입력·한글 조합 중에는 카드 단축키가 작동하지 않습니다. `?` 또는 `조작법`에서 전체 입력을 확인합니다.
- 접힌 `기록`을 펼쳐 배치를 되돌리거나 Fork합니다. 과거 배치에서 새로 조작하면 원래 기록을 보존하는 별도 가지를 만듭니다.

조작은 [공식 가상 테이블 조작법 조사](docs/table-ux.md)를 바탕으로 정했습니다. 제품마다 키가 달라 모든 단축키를 하나의 보편 표준으로 주장하지 않습니다. 별도의 좌우 패널이나 카드마다 반복되는 버튼은 없습니다.

조사·소유권·공개·법정·승패는 자동 처리하지 않습니다. 진행 방식은 사용자가 결정합니다. 앞뒤 상태는 로컬 화면 표시일 뿐 접근 권한이나 멀티플레이 비밀 보장이 아닙니다. 현재 배치와 기록은 메모리에만 유지되어 새로고침하면 초기화됩니다. 기존 게임 규칙 엔진은 소스에 보존하되 테이블에서는 사용하지 않습니다.
