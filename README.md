# Murder Mystery Workbench

AI가 생성한 머더 미스터리 시나리오를 검증하고 카드 기반으로 시험하는 워크벤치입니다. Phase 1에는 《왕관재판》 한 라운드의 카드 라이브러리와 수동 테스트 실행이 포함됩니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 시나리오 수정

정본 데이터는 `scenarios/crown-trial/`의 분할 JSON입니다. 파일을 수정하면 개발 서버가 화면을 다시 불러오며, `schemas/`의 JSON Schema와 의미 검증기가 잘못된 타입·참조·도달 불가 카드를 보고합니다.

```text
scenarios/crown-trial/
├── scenario.json
├── characters.json
├── cards.json
├── locations.json
└── rules.json
```

## 카드 라이브러리와 시나리오

카드 라이브러리의 `전체 / 기억 / 소문 / 물증 / 증언` 버튼으로 종류를 선택합니다. 전체 보기에서도 종류별 구역으로 나뉘며 검색은 선택한 종류 안에서 카드 본문·인물·장소·태그를 함께 찾습니다. 카드 클릭 시 전체 본문과 시작 위치·현재 소유자·연결된 주장을 확인합니다.

현재 콘텐츠는 **기억 12장, 소문 6장, 물증 12장, 증언 6장**입니다. 여섯 인물은 각자 기억 2장으로 시작하며, 나머지 24장은 서재·약제실·서쪽 회랑·왕실서고에서 조사합니다. 테스트 실행의 손패에서 인물 설정서를 펼칠 수 있습니다.

[공유 시나리오 대화](https://chatgpt.com/share/6aae7427-be78-83e8-a187-57c34bf29843)의 후반 사건 진상과 인물 설정을 바탕으로 문구를 확장했습니다. 세라핀은 선왕의 딸이며, 주요 시간 단서는 `21:52 폭행 → 22:18 생존 → 22:30 술 호출 → 22:36 생존 → 22:44 재상 방문`입니다. 진상은 유지하되 카드의 구체적인 문구·문서 조각·목격 범위는 테스트용으로 각색했습니다.

라이브러리는 모든 비밀을 보는 설계자 공간입니다. 현재 한 라운드 샌드박스에는 이 조사 카드들이 모두 배치되어 있습니다. 전체 게임의 라운드별 분배·해금 조건·밸런스는 아직 확정하지 않았습니다. 연결된 주장은 자동으로 참이 되는 정답이 아니라 법정에서 판정할 명제입니다.
