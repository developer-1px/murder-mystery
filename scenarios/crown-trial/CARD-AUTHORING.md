# 왕관재판 카드 원고 · 제작자용

90장의 공통 카드 묶음이다. 카드 문구는 원문을 바탕으로 쓴 플레이용 각색이다.

| 종류 | 장수 | 3장 선택 묶음 |
| --- | ---: | ---: |
| 기억 | 18 | 6인 × 시작 3장 |
| 소문 | 24 | 3장 제시, 선택 카드만 제거 |
| 물증 | 24 | 장소 4곳 × 6장 |
| 증언 | 24 | NPC 6명 × 4장 |
| 전체 | 90 |  |

탐문 NPC는 플레이어 캐릭터와 1:1로 대응한다. 마르타–엘레노라, 니콜–카시안, 루시엔–이사벨, 엘리안–세라핀, 오스윈–베네딕트, 하르트–로웬의 여섯 쌍이다. 각 NPC 덱은 4장이다. 매회 여섯 플레이어가 서로 다른 NPC를 한 명씩 맡고, 2장을 읽어 1장을 획득한다. 선택하지 않은 카드는 덱에 남으며 같은 NPC는 다음 회차에 다시 탐문할 수 있다. 따라서 3회가 끝나면 각 NPC 덱에서 정확히 3장이 획득되고 1장이 남는다. 상세 묶음은 `npc-groups.json`에 기록했다.

소문은 각자 3장을 읽고 1장을 공개하며 나머지는 덱에 남긴다. 물증은 장소마다 6장이다. 한 명이 조사하면 2장, 같은 장소를 고른 사람이 N명이면 남은 카드 중 N+1장(부족하면 전부)을 함께 보고 각자 1장씩 획득한다. 남은 카드가 N장보다 적은 장소에는 그 인원이 함께 들어갈 수 없다. 선택하지 않은 카드는 덱에 남긴다.

세 회차가 끝나면 소문·증언·물증은 각각 24장 중 18장이 획득되어 종류별 노출률이 75%로 같다. 각 종류에서 6장이 읽히지 않거나 선택되지 않은 채 남을 수 있으므로, 핵심 결론은 특정 한 장의 획득을 전제로 하지 않는다.

## 시나리오 기준

참고한 [공유 대화](https://chatgpt.com/share/6aae8f28-d7f0-83ee-af3a-2954810704be)의 초기 사건 진상과 6인판 조정을 바탕으로 한다. 초기안의 발렌 백작은 포함하지 않는다.

엘레노라의 독살 지시와 취소, 카시안의 폭행, 이사벨의 수면제와 문서 수색, 로웬의 경비 철수와 기록 수정, 베네딕트가 입을 막고 몸을 제압한 행위, 세라핀의 서고 조사를 공통의 밤으로 사용했다. 후속 조정안의 로웬 재방문과 불확실한 이사벨의 목격을 반영했다.

카시안의 친부는 베네딕트다. 선왕은 이를 알고도 카시안을 자신의 적법한 아들로 인정했다. 친생 관계와 법적·정치적 지위는 서로 다른 쟁점이다. 이사벨의 태아는 연인 관계나 진료 날짜만으로 친부를 확정하지 않는다.

**행위, 실제 사망 원인, 법정에서 인정한 책임을 구분한다.** 정본 진상은 베네딕트가 의식이 흐린 아드리안을 제압하는 동안 호흡을 막아 사망하게 한 것이다. 어느 카드 한 장도 이를 선언하지 않는다. 생존 시각, 알리바이, 비치명적 외상·약물, 서재 출입, 의복 흔적을 함께 모아야 결론에 도달한다.

이사벨은 무고한 다섯 인물 중 공개 정보만으로 사망 시간대의 알리바이가 없는 유일한 인물이다. 카시안이 22시 39분부터 22시 52분까지의 비밀 만남을 공개하고 두 사람의 편지 조각이 이를 뒷받침할 때만 알리바이가 성립한다. 따라서 카시안은 이사벨을 구하려면 관계와 아이의 친부 의혹이 드러날 위험을 감수해야 한다.

## 시간과 기존 원고의 수정

6인판 FIX v1을 기준으로 맞춘 사건 순서는 다음과 같다.

| 시각 | 사건·관측 |
| --- | --- |
| 18:30 | 만찬, 유언장 요구 |
| 19:20 / 19:35 | 약제 반출 / 왕비의 명령 취소 |
| 20:20 / 20:40 | 세라핀 서고 출입 / 첫 술 |
| 21:52 | 카시안의 폭행과 회중시계 파손 |
| 22:00 / 22:08 | 경비 철수 / 술 호출 |
| 22:15 | 로웬의 첫 방문과 직접 대화 |
| 22:22~22:25 | 마르타가 술병을 놓음 / 아드리안의 음주. 마르타는 음주를 보지 못함 |
| 22:33 | 이사벨 방문. 후속 조정안에 따라 반응을 확신하지 못함 |
| 22:40 / 22:50 | 세라핀 서고 열람대 목격 / 같은 자리의 두 번째 전언 |
| 22:38~22:49 / 22:52 | 베네딕트의 서재 출입, 22:41경 치명적 제압 / 찢어진 정복 수선 의뢰 |
| 22:39~22:52 | 이사벨과 카시안의 비밀 만남 |
| 22:40~22:48 | 로웬이 서쪽 외문의 점검과 교대 인계에 참여 |
| 22:55 전후 / 23:05 | 로웬의 두 번째 방문 / 시신 발견 |

기존 카드의 22:18·22:36·22:44와 첫 술의 21:40을 수정했다. 시종이 마르타의 술병을 방 안으로 운반했다는 이전 각색도 제거했다. 기존 참조 호환을 위해 `claim.alive-2218`, `claim.alive-2236` ID는 유지하되 표시 문장은 각각 22:15, 22:33으로 수정했다. ID의 숫자는 사건 시각의 근거가 아니다. 특히 22:33 생존 주장은 법정의 판정 대상이며 확정 관측이 아니다.

## 추가한 단서의 연결

이 표는 제작자용이다. 카드 앞면·태그에 해설로 붙이지 않는다.

상세 분류는 `issue-groups.json`에 기록한다. 각 핵심 쟁점을 여러 정보 조각으로 나눈 뒤 카드 ID를 연결했다. 같은 카드가 서로 다른 쟁점의 경계 역할을 하면 중복 연결한다. 이 파일의 질문과 감사 메모는 설계 검토용이며 플레이 중 공개하는 카드 정보가 아니다.

| 쟁점 | 연결한 카드 | 남겨 둔 한계 |
| --- | --- | --- |
| 독과 명령 | 장부·수령표·약제사 / 마르타 / 재호출 쪽지·심부름꾼 | 반출·살해 지시·취소·음주 목격을 구분 |
| 약물·외상 | 두 잔·술병·처방전·정량 검사·상처 검시 | 각 카드 하나로 사인을 확정하지 않고 함께 보아 치명 원인을 배제 |
| 폭행 이후 | 회중시계·호출 기록·로웬·문밖 시종 | 시계 정지·호출·실제 대화를 구분 |
| 호출 기록 | 기록원·점검표·설비 담당자 | 기록원과 방문 시종은 완전히 독립된 목격이 아님; 전날 고장은 당일 호출이 거짓이었다는 증명이 아님 |
| 검은 천 | 천 조각·수선된 정복·수선 담당자·직물 견본·의복 담당자 | 직물 종류만으로 특정하지 않고 찢긴 모양과 시간까지 결합 |
| 재상의 동선 | 발송 문서·서기·회랑 시종 | 접수 시각과 서명 시각은 다름 |
| 로웬의 동선 | 교대 수첩·일지·흡묵지·두 번째 방문·순찰병 | 부하 위치와 대장 위치, 복도 목격과 방 안 목격을 구분 |
| 이사벨 | 혼인 청원 초안·편지·시녀·건의서 | 혼인 무효는 아직 청원 초안; 아이의 왕위와 본인의 권한을 구분 |
| 태아 | 진료기록·달수 소문·연인들의 기억 | 친부 확정 단서로 사용하지 않음 |
| 세라핀 | 조약·부속 문서·사절 / 계승법·출생 등록부·선왕 문서 | 서명·변경 협상·계승 심의 자격을 자동 혼인·자동 즉위로 바꾸지 않음 |
| 혈통 | 당사자 기억·옛 편지 / 출생 등록부·인정 증서·산파 | 혈통과 선왕의 법적 인정을 구분. 산파는 수태나 연인 관계를 보지 못함 |
| 근위대 | 선왕 지시서·경비 기록·로웬의 기억 | 로웬 개인의 책임과 조직의 미래를 구분 |

## 카드 작성 기준

- 물증에는 관찰 가능한 사물 상태와 문서 내용만 쓴다. 제목·본문·태그 모두 원인·행위자·동기의 추정, 혐의 판단, 추리 지시를 제외한다.
- 문서의 이름·서명·명령·청원과 실제 작성자·행위·이행 결과를 구분한다.
- 증언 본문은 직접 말하는 인용문만 쓴다. 화자 소개나 서술자의 해설을 붙이지 않는다. 보지 못한 것과 불확실한 기억은 인물이 직접 말한다.
- 기억은 해당 인물의 행위·관찰·당시 생각을 담으며 사인을 전지적으로 알려주지 않는다.
- 소문은 전달 경로와 떠도는 말을 담고 확인된 사실로 승격하지 않는다.

`rules.json`의 주장과 `claimId`는 법정의 판정 대상이다. 카드와 연결됐다는 이유만으로 참이 되지 않는다. 물증에 주장 설명을 해설로 붙이지 않는다. 이번에 정치·혈통·혼인·재방문 등의 주장 12개를 추가했다.

## 배포

각 인물에게 개인 진실 I·II·III를 한 장씩 배정하고 정해진 시점에 공개한다. 선왕의 봉인 문서와 오래된 편지를 포함한 물증은 모두 장소 덱에서 조사한다.

개인 진실은 총 18장이다. 소문·탐문·탐색·재판을 한 회로 하여 세 번 반복한다. `release-plan.json`의 기존 라운드 목록은 카드 공개 시점 검토용 초안이며, 실제 선택은 종류별 덱에서 진행한다.

현재 워크벤치는 배포안으로 자동 해금하지 않는다. 라이브러리에서는 90장 전체를 검토할 수 있다. 조사 횟수·랜덤 배치·밸런스까지 검증된 완성 배포안은 아니다.

개인 진실 I~III는 이 90장에 포함된다. 최종 판결과 결단 선택지는 별도 규칙으로 남아 있다.

문서 양식·편지 전문·부속 조항·발언과 관찰 세부는 이번에 보충한 각색이다. 새 법률 문구는 가상 왕국의 시험용 문구이며 계승·혼인 결과를 자동 판정하는 규칙으로 구현하지 않았다.
